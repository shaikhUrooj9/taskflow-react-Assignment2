# TaskFlow React + TypeScript

TaskFlow is a React + TypeScript task manager project developed for CS4717 Web Technologies I Phase 2 Assignment.

## Features

- React + TypeScript
- React Router
- Task List Page
- Create Task Page
- Add Task
- Delete Task
- Edit and Update Task
- Form Validation
- Responsive Design

---

## Technologies Used

- React
- TypeScript
- Vite
- React Router DOM
- CSS

---

## Project Setup

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

Move into project folder:

cd taskflow

Install dependencies:

pnpm install

Run development server:

pnpm run dev

Open browser:

http://localhost:5173
